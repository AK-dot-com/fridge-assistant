# 🧊 冷蔵庫アシスタント

冷蔵庫にある食材から作れるレシピを検索し、不足食材の確認や買い物リスト作成まで行えるWebアプリです。

## Demo

GitHub Pagesで公開しています。

URL：https://ak-dot-com.github.io/fridge-assistant/
---

# ① アプリ概要

「冷蔵庫にある食材を無駄なく使いたい」という課題を解決するためのレシピ検索アプリです。

所持している食材を入力すると、材料の一致度から作れるレシピを検索し、不足している食材や買い物リストを確認できます。

単なるレシピ表示ではなく、日常的な利用を想定し、

* 献立決めの負担軽減
* 食材ロス削減
* 買い忘れ防止

を目的として制作しました。

# ③ 解決する課題

| 課題           | 解決方法         |
| ------------ | ------------ |
| 献立を考える時間がかかる | 食材からレシピ候補を検索 |
| 食材を余らせる      | 冷蔵庫内の食材を活用   |
| 買い忘れが発生する    | 不足食材を買い物リスト化 |
| 同じ料理が続く      | 複数レシピ候補を表示   |

---

# ④ 主な機能

| 機能     | 内容                           |
| ------ | ---------------------------- |
| 食材入力   | タグ形式で追加・削除（Enter入力対応、候補表示あり） |
| レシピ検索  | 入力食材との一致率を算出して候補表示           |
| レシピ詳細  | 材料・手順をモーダル表示                 |
| 不足食材表示 | 所持食材との差分を抽出                  |
| 買い物リスト | 追加・チェック・削除可能                 |
| お気に入り  | レシピを保存可能                     |
| テーマ切替  | ライト・ダークモード対応                 |

# ⑤ データ取得設計について

## recipes.jsonを採用した理由

本アプリでは、レシピデータ取得部分を`fetch()`によるJSON取得として実装しています。

当初、楽天レシピAPIの利用も検討しましたが、提供されているAPIはカテゴリ別ランキング取得が中心であり、

「冷蔵庫にある食材から横断的にレシピ検索する」

という本アプリの主要機能には適していませんでした。

そのため今回は、APIレスポンスを想定した形式の`recipes.json`を作成し、実際の通信処理として取得する構成にしました。

```text
recipes.json
      ↓ fetch()
js/api.js
      ↓
レシピ検索処理
      ↓
画面表示
```

単なる固定データ読み込みではなく、将来的に外部APIへ置き換えられるよう、

* データ取得処理
* 検索ロジック
* UI表示

を分離しています。

外部APIへ移行する場合は、`js/api.js`の取得先とデータ変換部分を変更することで対応できる設計です。

# ⑧ LocalStorage設計

ユーザー状態の保存にはLocalStorageを利用しています。

| キー              | 内容       |
| --------------- | -------- |
| favoriteRecipes | お気に入りレシピ |
| shoppingList    | 買い物リスト   |
| theme           | 表示テーマ    |
| recentSearch    | 最近検索した食材 |

ログイン機能は未実装のため、保存データはユーザーアカウント単位ではなく、ブラウザ単位で管理しています。

---

# ⑨ エラー処理

通信や操作時の状態を考慮し、以下のエラー表示を実装しています。

* JSON取得失敗
* 通信エラー
* 検索結果0件
* 食材未入力

通信失敗時にはユーザーが原因を把握できるよう、エラーメッセージと再試行ボタンを表示します。
